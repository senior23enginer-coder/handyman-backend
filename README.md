# handyman-backend

## Ficha del proyecto

Backend Java del proyecto Handyman, estructurado como aplicación Maven.

### Contenido

- [src](./src), [pom.xml](./pom.xml).

### Uso

Revisa [pom.xml](./pom.xml) para consultar la versión de Java, las dependencias y los módulos Maven. Configura los servicios externos por separado.

- [Repositorio de origen](https://github.com/mac2394q/handyman-backend)
